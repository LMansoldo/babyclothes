# Tipografia

Famílias tipográficas do BabyClothes.

## Londrina Solid

| Token | Font | Uso |
|-------|------|-----|
| `--font-londrina` / `--ld` | Londrina Solid, cursive | Exclusivo para logotipo/wordmark |

Weight 400.

## Cormorant Garamond

| Token | Font | Uso |
|-------|------|-----|
| `--font-cormorant` / `--sr` | Cormorant Garamond, serif | Fontes display/editorial |

| Weight | Size | Uso |
|--------|------|-----|
| 300 | 3.5rem | Títulos de página |
| 400 | 2.25rem | Headings |
| 600 | 1.75rem | Subtítulos |
| 400 italic | 1.35rem | Eyebrows |

## Lato

| Token | Font | Uso |
|-------|------|-----|
| `--font-lato` / `--vd` | Lato, sans-serif | Corpo de texto |

| Weight | Size | Uso |
|--------|------|-----|
| 300 | 0.75rem | Texto auxiliar e labels secundários |
| 400 | 0.875rem | Texto corrido, descrições, placeholders |
| 700 | 0.875rem | Labels, títulos de cards, nomes |
| 900 | 1rem | Destaques, preços principais |
| 700 uppercase | 0.6rem | Labels de seção, categoria, meta |
